# Aramco Geoscience Job Watch

This file is the running log for an automated weekly check of Saudi Aramco
geoscience/geophysics openings (via `careers.aramco.com` and web search,
since `careers.aramco.com` is not directly fetchable from this environment
and results come from web search snippets instead).

A scheduled Routine re-runs the search periodically, diffs against the
"Known postings" list below, and reports anything new to the user. It
updates this file and commits the change after each run.

**No applications are ever submitted automatically.** This is a watch/alert
tool only.
